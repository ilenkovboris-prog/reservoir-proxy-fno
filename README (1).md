# Прокси-модель давления в пласте на базе Fourier Neural Operator

## Промежуточный итог: замена гидродинамической симуляции нейросетью для однофазного потока

Проект исследует, можно ли заменить часть расчётов классического гидродинамического
симулятора (MRST) обученной нейросетью-суррогатом (Fourier Neural Operator), сохранив
приемлемую точность и получив ускорение на порядки.

Задача выбрана осознанно узкой — это первый, полностью управляемый шаг перед
переходом к более сложным постановкам (двухфазный поток, реальная геология,
физически-информированные ограничения).

---

## Постановка задачи

- Пласт: однородная по толщине область 40×40 ячеек, однофазный несжимаемый поток
- Проницаемость: синтетическое случайное поле (гауссовское, log-normal), генерируется заново для каждого сэмпла
- Скважины: 6 штук на train/val, случайные координаты; половина нагнетательные (BHP 150 бар), половина добывающие (BHP 50 бар)
- Цель модели: по полю проницаемости и расположению скважин предсказать установившееся поле давления, минуя честный гидродинамический расчёт

## Пайплайн

```
MRST (Octave)                 Python / PyTorch (Google Colab)
──────────────                ─────────────────────────────
generate_data.m         →     dataset (.mat → тензоры)
  - logNormLayers/              - log10 + min-max нормализация проницаемости
    gaussianField                - min-max нормализация давления
  - случайные скважины           - гладкие гауссовы маски скважин (не точки)
  - incompTPFA solver     →     - аугментация отражениями (×4)
                                 ↓
                               SimpleFNO (spectral conv, 3 слоя)
                                 ↓
                               обучение (Adam, relative L2 loss)
                                 ↓
                               blind-test на отдельно сгенерированной
                               выборке (другие сиды + другое число скважин)
```

Данные: 2000 сэмплов train/val + 100 сэмплов слепой выборки (40 с тем же числом
скважин на новых сидах, 30 с 4 скважинами, 30 с 8 скважинами — специально для
проверки генерализации на конфигурации, которых модель не видела).

## Эволюция подхода (что пробовали и почему)

| Версия | Изменение | Результат |
|---|---|---|
| v1 | Точечные маски скважин, 300 сэмплов | skill ≈ 0.5, нестабильно |
| v2 | + гладкие гауссовы маски, + канал log-расстояния до скважин, width 32→64 | Переобучение: train/val разошлись в 3-4 раза |
| v3 | То же на 2000 сэмплах вместо 300 | skill 0.91 (train), но провал генерализации на 4/8 скважин (медиана 0.63 / 0.77, отдельные случаи катастрофические) |
| **v4/v5** | **Убран канал log-расстояния** (см. обоснование ниже) | **Медианный skill ≈ 0.85 одинаково для 4/6/8 скважин** |

### Почему убрали канал log-расстояния

Канал считался как **сумма** логарифмов расстояний от каждой ячейки до всех скважин
данного типа. При обучении сумма всегда состояла из 3 слагаемых (3 нагнетательных).
На тесте с 4 или 8 скважинами число слагаемых менялось, и весь канал систематически
сдвигался по масштабу за пределы диапазона, знакомого модели — независимо от самой
геометрии расположения. Это и объясняло провалы генерализации в v3.

Решение: оставить только **локальное** кодирование скважин — гладкое гауссово пятно
на месте каждой скважины, без глобальной агрегации по всем скважинам сразу. Формат
входа перестаёт зависеть от их количества.

## Текущие результаты (v5)

**Обучение (2000 сэмплов, синтетическая геология):**
- val loss (relative L2): 0.064
- skill (train pool): 0.91

**Слепая выборка (100 файлов, независимые сиды):**

| Скважин | N | MAE, бар | Skill (медиана) | Skill (худший) |
|---|---|---|---|---|
| 4 | 30 | 4.35 | 0.860 | -15.81 |
| 6 | 40 | 4.23 | 0.850 | -0.71 |
| 8 | 30 | 4.58 | 0.852 | +0.03 |

Медианы почти совпадают между группами — модель обобщается на число скважин, которого
не видела при обучении. Среднее заметно ниже медианы из-за единичных выбросов, не
систематической слабости (см. диагностику ниже).

## Диагностика выбросов

Проверены гипотезы о причине единичных провальных случаев:

| Фактор | Корреляция со skill |
|---|---|
| std давления в сэмпле | +0.32 |
| std проницаемости | +0.06 |
| max/min проницаемости | -0.00 |
| std log10(проницаемости) | -0.03 |
| мин. расстояние между скважинами | +0.08 |
| мин. расстояние скважины до края сетки | +0.02 |

Ни один фактор не даёт сильной корреляции. Вывод: провалы не имеют единой системной
причины — это комбинация (а) чувствительности самой метрики skill на почти плоских
полях давления (маленький знаменатель в формуле объяснённой дисперсии) и (б) отдельных
трудных сочетаний геометрии, не покрытых текущим объёмом обучающих данных. При этом
MAE в барах на этих же случаях остаётся в разумных пределах — 4-10 бар при диапазоне
давлений 50-150 бар.

## Ограничения текущей версии

- Только однофазный стационарный поток — нет насыщенности, нет временной динамики
- Синтетическая геология (гауссовское случайное поле), не калибровано на реальный пласт
- Фиксированные значения BHP скважин (150/50 бар), не варьируются между сэмплами
- Сетка 40×40, без вертикальной неоднородности (один слой по Z)
